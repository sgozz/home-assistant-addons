# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - Initial Release

### Added
- Initial release of Foundry VTT add-on
- Support for multiple architectures (aarch64, amd64, armhf, armv7, i386)
- Integration with felddy/foundryvtt container
- Configuration options for Foundry VTT credentials
- Web UI access on port 30000
